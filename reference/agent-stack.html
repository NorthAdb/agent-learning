Agent / Harness 用语速查

阶段 0 用这些词当载体；阶段 1 起会正式加深。这里只保证「本仓库里一词一义」。

术语本仓库含义_Avoid_（别混用）
Model 提供推理与决策的 LLM（司机）。 把整个产品叫「模型」
Harness 让模型能在具体环境干活的外壳：Tools + Knowledge + Observation + Action + Permissions（车）。 把任意 prompt 链都叫 harness
Tool 模型可调用的一个动作（读文件、检索、shell…），通常有 name + arguments。 插件 / Skill（后两者以后再收紧）
Tool call 一次具体调用请求，常用 dict：name + arguments。 把整轮对话叫 tool call
Agent loop while：模型输出 →（可选）执行 tools → 观察 → 再调用模型，直到 final 或触顶。 单次补全、无工具的一次性问答
max_turns loop 安全带：限制最大轮数，防死循环。 当成模型温度参数
RAG 检索增强生成：先查知识再生成；在本使命里常作为 harness 的 Knowledge/工具能力二次开发切入点。 「装了向量库 = 做完 Agent」
封装层 如 LangChain / LangGraph：编排与工程脚手架；要会，且能对照自建 harness。 把封装层等同于 Agency 来源

一句话栈（面试草稿）

产品 ≈ Model（决策） + Harness（工具/上下文/权限/观测）
Agent loop 把「决策 ↔ 工具结果」转起来
RAG 是 Knowledge 的一种接入方式
LangGraph 等是编排实现选项，不是 Agency 本身
