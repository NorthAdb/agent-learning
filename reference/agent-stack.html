Agent / Harness 用语速查

阶段 0 用这些词当载体；阶段 1 见 公式 与 Agency / Harness。这里保证「本仓库里一词一义」。

术语本仓库含义_Avoid_（别混用）
Model / LLM 提供推理与决策的大脑（书：LLM）。Agency 的来源。 把整个产品叫「模型」
Agency 感知—推理—行动的能力；来自训练，不是编排代码赋予的。 以为节点图能「做出」agency
Harness 载具：最小 = 上下文管理 + 工具接口；生产再加约束、验证、纠正。 把任意 prompt 链都叫 harness
Tool 模型可调用的一个动作（读文件、检索、shell…），通常有 name + arguments。 插件 / Skill（后两者以后再收紧）
Tool call 一次具体调用请求，常用 dict：name + arguments。 把整轮对话叫 tool call
Agent loop while：想 → 做 → 看，直到无 tool call 或触顶。书称 ReAct；见 0019 速查。 单次补全、无工具的一次性问答
max_turns loop 安全带：限制最大轮数，防死循环。 当成模型温度参数
Environment Agent 与之交互的外部世界。不在公式「LLM + 上下文 + 工具」里。 把环境算进公式右边；以为磁盘有文件模型就看见
工作流 路径由代码写死；LLM 只在节点内生成。不是本仓库默认的自主 Agent。 把节点图 / 提示词链直接叫 Agent
能力鸿沟 基准好看、真实任务差。见 0020。 当成「换个更贵模型就行」
验证缺口 它说做完了 ≠ 命令验证过了。见 0020。 当成模型人格「爱撒谎」
RAG 检索增强生成：先查知识再生成；是 Knowledge 的一种接入方式，不是 Agent 本身。 「装了向量库 = 做完 Agent」

一句话公式

Agent = LLM + 上下文 + 工具
产品 ≈ Model（决策）+ Harness（工具 / 上下文 / 权限 / 观测）
Agent loop 把「决策 ↔ 工具结果」转起来

对照路径见 学习路径：三份材料怎么配。
