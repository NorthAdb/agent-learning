OOP 进阶（0013）

概念要点
token / _x / __x公开可依赖；单 _ 约定内部（能读但不该当 API）；双 __ 改名为 _Class__x（防子类踩名，非沙箱）。勿与 __init__ 等 dunder 混淆
__slots__锁属性名名单：无 slots 可动态加；名单内可读写；名单外 AttributeError。不是 private

@propertygetter 读（无括号）；@名.setter 写；无 setter → AttributeError（只读）；对内 _x
三种方法实例 self=成品；static 纯函数无 self；class 的 cls=图纸，工厂（造实例的入口）须 return cls(...)

坑 以为 _x 会语法报错；obj.area() 给 property 多加括号；staticmethod 里写 self；classmethod 写死类名不用 cls。

getattr / subprocess / glob（0014）

为何学：s01 读 SDK 块 + 跑 bash；s02 按模式找文件。三件是硬依赖，不是点缀。

概念是什么 / 解决什么
getattr(obj, n, default)按字符串读任意对象的属性/方法（含 list 等）；缺了给默认。不是取下标/dict 键。SDK 块用它；dict 键用 .get
subprocess.run起 OS 子进程并等结束（bash 工具）。argv、capture_output、text、timeout；看 returncode；超时抛异常
glob / grepglob：通配文件名，无匹配是空；grep：搜文件正文（概念对照，无标准库同名模块）
getattr(block, "type", None)
subprocess.run(["python", "-c", "print(1)"], capture_output=True, text=True, timeout=10)
list(Path(".").glob("*.py"))

坑 对象用 []、dict 用点号；不设 timeout；只看 stdout 不看 returncode；以为非零退出必抛异常；glob 无匹配当成错误；自己的脚本乱用 shell=True。

线程与时间（0016）

为何学：慢命令后台跑、共享 dict 加锁、记时间、dataclass 落 JSON、模块级计数器。不是 async。

概念是什么 / 解决什么
Thread(target=fn, args=, daemon=True)target 函数对象不要加括号；单元素 args 要逗号；start 立即返回；join 才等；daemon 随主进程结束
with lock:保护多线程共享 dict；改状态锁内，sleep/慢活锁外
datetime.now()当前时间；timedelta 做差；strftime 给人看；isoformat 给程序存
asdictdataclass → dict，再 json.dumps
global函数里重新赋值模块级名才要；只读/改对象内部不必

坑 target=fn()；args=("x") 少逗号；无锁改共享 dict；以为 daemon 会干完；直接 dumps dataclass；锁内长时间阻塞；+= 忘了 global。

文件与异常

概念稳定规则Agent / RAG 用途
路径三案cwd 相对名 / Path(__file__).parent / 绝对路径；默认选脚本目录定位知识库、日志与配置
exists vs resolveexists() → bool（有没有）；resolve() → 绝对 Path（写清地址）先检查再读；日志里打印绝对路径
Path 零件.parent / / / .name / .suffix / iterdir()拼路径、筛扩展名、扫知识库目录
open / read_textr/w/a/x；文本显式 UTF-8；大文件逐行，小文件可用 read_text读取文档、写运行日志
with离开代码块自动关闭文件，即使发生异常也会清理资源安全管理文件、网络连接等资源
异常标准范式窄 try → 具体 except →（可选）else / finally；决策：能恢复 / 改语义上抛 / 冒泡；文件清理优先 with工具边界、知识库加载、Agent loop 收口
as errorexcept E as error 接住实例；type(error).__name__ 取类型名；raise ... from error 保留原因链边界改写错误消息、日志分类
异常三策略局部恢复 / 转换上抛 / 不捕获（范式决策的落点）单文件可跳过；边界补语义；库代码可冒泡
else / finallyelse 仅在无异常时执行；finally 总会执行成功后统计；释放必须释放的资源
raise在边界把低层错误转换成更有语义的错误把“文件不存在”变成“知识库加载失败”
from pathlib import Path

path = Path(__file__).parent / "knowledge.txt"
print(path.exists())     # True/False
print(path.resolve())    # 绝对路径，便于日志

# 标准范式：窄 try + 具体 except + else；边界可 raise ... from error
try:
    text = path.read_text(encoding="utf-8")
except FileNotFoundError as error:
    text = ""            # 策略1：局部恢复
    print(type(error).__name__)
else:
    print("读取成功")

# 策略2：raise FileNotFoundError(f"...: {path}") from error
# 需要写入时：w / write_text 会清空；a 会追加
with open(path.parent / "run.log", "a", encoding="utf-8") as file:
    file.write("one event\n")

坑 open("knowledge.txt") 相对 cwd；exists 与 resolve 问的不是同一件事；w/write_text 会截断；批量加载勿把局部恢复写成“静默空库”；禁止裸 except:。

HTTP / requests

概念稳定规则Agent 用途
GET / POSTGET 查资源；POST 提交 JSON 身体检索、chat completions、业务 API
参数放哪url 地址；params 查询串；json 身体；headers 头；timeout 超时写工具时按抽屉填，勿混用
params查询串自动编码；别手拼 URL/rag/search?q=
json= vs data=json= → application/json；data=dict → 表单；必须写关键字名模型 API 用 json=
headersdict[str,str]；Bearer 放 Authorization鉴权、User-Agent

异常Timeout / HTTPError / RequestException → 边界转换上抛工具失败观察
import requests

# GET
r = requests.get(url, params={"q": "x"}, timeout=5)
r.raise_for_status()
data = r.json()

# POST：关键字 json= / headers= 不要漏写名字

    url,
    json={"model": "demo", "messages": []},
    headers={"Authorization": "Bearer TOKEN"},
    timeout=5,
)
r.raise_for_status()

坑 不设 timeout；只调 json() 不看状态；用 data=dict 当 JSON API；写成 post(url, payload) 漏掉 json=。

列表与元组

概念要点
创建[1, 2, 3]、list(range(5))、[0] * 6（乘不可变对象安全）
索引xs[0] 第一个；xs[-1] 倒数第一个；越界 IndexError（崩）
切片xs[start:end:step]，end 不含；越界给空 list不崩；返回新 list；xs[::-1] 反转
拷贝 / 引用ys = xs[:] 拷贝；ys = xs 共享同一 list，改 ys 改 xs
遍历for x in xs；for i, x in enumerate(xs)（start=1 编号从 1 起）；zip(a, b) 并列配对
增删append 加一个元素；extend 展平并入；pop() 删末尾并返回；remove 按值删
排序sorted(xs) 新 list；xs.sort() 原地且返回 None；reverse=True 降序
按字段排sorted(hits, key=lambda h: h["score"], reverse=True)
生成式[expr for x in xs if cond]：过滤在 if，投影在前；生成式优于手写 append
元组不可变 (1, 2)；一元组 (1,) 逗号不可省；a, b = pair 解包；a, *rest = xs 收走剩下的
交换a, b = b, a
嵌套list[dict]：hits[0]["score"]；list[list]：m[0][1]

坑 xs = xs.sort() 把 list 变 None；append([1,2]) 嵌套、extend([1,2]) 展平；[[]] * 3 三行共享同一个空列表，要独立用 [[] for _ in range(3)]。remove/index 找不到抛 ValueError（Java indexOf 返 -1）。
