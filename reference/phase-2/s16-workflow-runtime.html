s16：Workflow Runtime

一次 Workflow 工具调用跑完宿主脚本。续跑时未改的 agent() 读 journal。

来源： s16 README L98–187； code.py L455–565。

一张图

模型：Workflow(name, args, resume?)
  ↓
注册表取出可信脚本。未知名字 → 工具错误
  ↓
parallel 等齐；pipeline 按条目往下
  ↓
agent()+schema：不合法再试一次
  ↓
journal 键 = 类型|标签|prompt|schema 的哈希
  ↓
tool_result 只有最终结果。中间变量不进主对话

续跑

  • 名字、参数必须和快照一致。锁住整个 run。
  • 键命中且缓存仍符合 schema → cached，不再调用 runner。
  • 全部命中：agents=0 tokens=0。claim_agent 仍会计入 1000 次上限。
  • 嵌套 workflow() 只一层，共用这次 journal。

不负责

  • 不替换 s15 主循环。不接受模型上传脚本。
  • 不判断用户的最终目标是否达成。
  • demo 不打真实 API。resume 用上一份 runId。

过关句

编排 = 注册脚本 + 语义键 journal + 一次工具结果。 等齐用 parallel。按条目推进用 pipeline。
