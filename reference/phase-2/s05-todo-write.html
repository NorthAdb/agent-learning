s05：TodoWrite

计划先于行动；todo_write 只更新内存中的计划，不替 Agent 执行任务。

来源： s05 README L23–29； code.py L115–183。

一句话模型

todo_write tool_use
       ↓
PreToolUse → dispatch → TodoManager.update
                         解析 → 校验 → 整体替换 TODO.items → render
       ↓
tool_result 回到 messages → 模型决定下一步

一条 todo 的形状

[
  {"content": "阅读实现", "status": "completed"},
  {"content": "修改代码", "status": "in_progress"},
  {"content": "运行测试", "status": "pending"}
]
  • pending → [ ]：等待。
  • in_progress → [>]：进行中，最多一个。
  • completed → [x]：计划状态已完成，不等于测试已通过。
  • 最多 20 项；每项 content 去首尾空白后必须非空。
  • 每次 update 是全量替换，不是 append；要发送更新后的完整列表。

TodoManager 更新算法

  1. 若输入是字符串：先 json.loads，失败再用 ast.literal_eval。
  2. 检查顶层是 list，且长度不超过 20。
  3. 逐项检查是 dict；读取并规范化 content / status。
  4. 检查 status 属于三个允许值，并统计 in_progress。
  5. 超过一个进行中项目 → ValueError；旧状态不变。
  6. 全部通过后才执行 self.items = validated，然后 render。

工具接线

TOOLS 里声明：
"name": "todo_write"
"todos": {"type": "array", "maxItems": 20, ...}

TOOL_HANDLERS：
"todo_write": run_todo_write

循环：
handler = TOOL_HANDLERS.get(block.name)
output = handler(**block.input)
  • schema 是给模型的输入契约。
  • TodoManager 的 Python 检查才是写入内存状态前的运行时保护。
  • 注册存函数对象：run_todo_write，不要写 run_todo_write()。
  • **block.input 把参数字典拆成关键字参数。

schema / map L185–204； dispatch L320–332。

三轮提醒

rounds_since_todo = 0 if used_todo else rounds_since_todo + 1
if rounds_since_todo >= 3:
    results.append({
        "type": "text",
        "text": "<reminder>Update your todos.</reminder>",
    })
    rounds_since_todo = 0
  • 一轮 = 一次模型回复中含一个或多个 tool_use 的整批处理。
  • 一轮多个非 todo 工具仍只加 1。
  • 一轮只要出现一个 todo_write 就清零。
  • 无 tool_use 的回复不进入这段，先走 Stop。
  • 提醒是普通 text block，不是 tool_result，不是强制闸门。
  • 计数器是 agent_loop 局部变量；新用户 prompt 重新从 0。

源码 L292–340。

状态边界

东西保存什么生命周期
TODO.items 当前规范化后的完整 TODO 列表 同一 Python 进程；不自动落盘
messages 对话、assistant 回复、tool_result、提醒 同一 REPL 进程；本课也不持久化
rounds_since_todo 距上次使用 todo_write 的工具轮数 一次 agent_loop；每个新 prompt 清零
工作区文件 真实代码、文档和测试结果 由 file / bash 工具改变；与 TODO 分开

三组不要混淆

  • todo_write ≠ edit_file：计划状态 ≠ 文件副作用。
  • completed ≠ 验证通过：仍需 bash / 测试 / lint 的真实反馈。
  • schema ≠ runtime validation：声明形状 ≠ handler 已安全接受。
  • reminder ≠ permission：提醒模型 ≠ 拦截工具。
  • tool call ≠ tool-call round：一个 block ≠ 一轮模型回复。
  • json.loads / literal_eval ≠ eval：数据解析 ≠ 执行任意表达式。
