s01：一个循环 + Bash

真实 API 版的「想 → 做 → 看」：模型请求工具，Harness 执行，结果回到轨迹。 

messages
  → client.messages.create(model, system, messages, tools)
  → assistant.content
  → content 里有 tool_use 块？
       有：执行 → tool_result(tool_use_id) → messages → loop
       无：返回文本

四个边界

东西职责
Model / SDK client根据上下文决定是否调工具、传什么参数。
TOOLS给模型看的工具契约，不执行命令。
run_bashHarness 执行命令并收集 stdout / stderr。
messages保存 assistant 回复与 tool result，供下一轮观察。

字段配对

tool_use.id == tool_result.tool_use_id

tool_use 是模型的调用请求；tool_result 是执行后的观察。 循环看 content 里有没有 tool_use；stop_reason 仍在对象上，当前脚本不读它。有工具调用不表示命令已成功。

安全与平台边界

  • s01 的少数危险字符串拦截不是完整权限系统；权限在 s03。
  • shell=True 使用本机 shell；工具名叫 Bash 不保证 Windows 能执行 Unix 命令。
  • 首次运行使用可丢弃目录和只读任务；不要把 API key 放进 Git 或聊天。
