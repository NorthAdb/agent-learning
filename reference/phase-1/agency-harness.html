Agency vs Harness

两套公式叠在一起，不是互相作废。模型是驾驶者，harness 是载具。

Agency 定义： README-zh.md L9 （书 Ch1 无此词）。 第二套公式：书 §1.2 L270。 

0017  Agent = LLM + 上下文 + 工具
0018  Agent = Model + Harness

Model  = LLM（大脑）
最小 Harness = 上下文管理 + 工具接口
生产 Harness = 最小 + 约束 + 验证 + 纠正

Agent  ↔  Environment（仍在外面）

「我在开发 Agent」三案

实际在做本仓库怎么叫
调权重 / 后训练开发 Agency（不做）
拼上下文、暴露工具、权限与验证开发 Harness（要做）
节点图 / 规则树模拟智能不是（水管工 / 工作流）

生产三保障（本课只认名字）

词一句话
约束能做什么、不能做什么（权限、沙箱、审批）
验证做得对不对（测试、完成定义）；不听「我做完了」
纠正错了怎么补救（重试、回退）
