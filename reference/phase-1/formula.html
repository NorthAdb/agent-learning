Agent 公式

书 Ch1：加号是工程组合，不是强化学习里的「+」。环境不在公式里。

Agent = LLM + 上下文 + 工具
      = 大脑 + 眼睛 + 手脚

Agent  ↔  Environment（环境在外面）
零件比喻干什么缺了会怎样
LLM 大脑 理解意图、规划、决定下一步（含是否调工具） 只剩脚本 / cron，没有决策内核
上下文 眼睛 这一次决策能看到的全部信息（观察转成文本后的那一包） 仓库里有文件也等于看不见
工具 手脚 感知或改变外部世界的接口（读文件、跑命令、HTTP…） 只能纸上谈兵，改不了环境

三案 + 一条边界

有什么谁决定下一步本仓库怎么叫
只有 LLM（单次补全）—不是 Agent
LLM + 上下文，无工具—不是 Agent（能看不能做）
LLM + 工具，路径写死代码工作流，不是自主 Agent
LLM + 上下文 + 工具 + 循环模型自主 Agent
