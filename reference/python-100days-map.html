Python-100-Days 当作课本，学了多少

100-Days 是 Python 范围地图 / 课本，不是要读完 100 天。 课件 HTML 才是主教材：对应 Day 的要点写进课里，默认不必翻回原书。 冷门、纯趣味、和读 Agent 脚本无关的默认跳过。进 North 前按全套 s01–s20/code.py 补语法（0013–0016），不按 100 天把 Django / 爬虫 / 机器学习排进来。
