# 新名词必须能跳回教材原文

用户要求：每当课件出现新专有名词，要指出它在教材里的位置（文件 + 标题 + 行号），并给能点开的链接，方便去看原文。已写入 [[NOTES.md]] 的「新概念必须先讲」。当前先补阶段 1 的 0017 / 0018；此后新课默认带出处。

## Implications
- 定义不够：还要「打开哪一份、跳到哪一行」
- 教材没用这个词（如 Agency 在书 Ch1 未出现）必须写明，避免学生在书里空搜
- 2026-08-31 实测：书路径 `第01章 AI Agent 入门` 含空格，未编码的 `vscode://file/…` 会截断；本机 `vscode://` 协议还被 VS Code 抢走。行号跳转改用编码后的 `cursor://file/`；禁止用「同上」代替文件链接。
