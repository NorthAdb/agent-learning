变量与类型（读 Agent 代码用）

Agent 日志、工具参数、配置项全是「带类型的数据」。今天练的是：命名变量、认出 int/str/bool/list/dict，并用 f-string 打印——后面读 North / RAG 代码时处处用到。

最小知识

  • 变量 = 给一块内存里的数据取名；可改值。
  • 常用类型：int float str bool；后面立刻会碰到 list（有序）和 dict（键值）。
  • 动态类型：同一变量可以先后指向不同类型（Java 里你会皱眉；Python 里常见）。读代码时用 type(x) / isinstance(x, dict) 自查。
  • f-string：f"model={name} temp={temp}"，调试 Agent 配置最快。
