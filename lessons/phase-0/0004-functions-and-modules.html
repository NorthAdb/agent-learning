系统讲解

1. 为什么要函数

Day14 用「求三次阶乘」开场：三段几乎一样的循环。 Python 官方教程 和教材的结论一样：把独立且会重复的逻辑封进函数，需要时调用而不是复制。 Agent 里同样：run_tool 每轮每个 tool_call 都要走一遍，必须是函数，不能把实现贴进 loop。 

def fac(num):
    result = 1
    for n in range(2, num + 1):
        result *= n
    return result

print(fac(7) // fac(3) // fac(4))  # 组合数 C(7,3) = 35

已有现成实现就别自己造：标准库是 from math import factorial。Agent 侧同理——检索、HTTP、JSON 优先用库。

2. 定义、返回值、None

def 名字(参数): 下一行起缩进的块就是函数体。 return x 把值交回调用方并立刻结束函数。 没有 return 时，Python 返回 None（不是「没有值」这种 Java void，而是一个真对象）。 没有 return ≠ 函数体不执行。 调用 log_only("hi") 时，里面的 print 照常跑（这是副作用）；函数结束后才把 None 交回。 所以 print("log_only ->", log_only(...)) 会先打印 (logged)，再打印 log_only -> None——外层 print 必须先把括号里的调用算完，才能打印那个返回值。 

def wrap_observation(text: str) -> dict:
    return {"role": "tool", "content": text}

def log_only(text: str) -> None:
    print("logged", text)   # 没有 return

obs = wrap_observation("ok")   # dict
x = log_only("hi")             # x is None

text: str 和 -> dict 是类型标注：给读代码的人（和检查器）看，不改变运行结果。 Day15 会写更长；本课只要看见别慌。 0003 文件开头的 from __future__ import annotations 让这些标注延迟求值，现在当注释即可。

3. 位置参数、关键字参数、默认值

调用时可以按位置从左到右传，也可以 名字=值。官方规则：关键字参数必须写在位置参数后面；带默认值的形参必须写在不带默认值的后面。

def call_model(prompt, temperature=0.2, max_tokens=256):
    return f"{prompt!r} t={temperature} n={max_tokens}"

call_model("hi")                          # 后两个用默认值
call_model("hi", 0.0)                     # 位置：temperature=0.0
call_model("hi", temperature=0.0)         # 关键字：可读，顺序可换
call_model(max_tokens=32, prompt="hi")    # 合法：关键字可乱序
# call_model(temperature=0.0, "hi")       # 语法错：位置参数不能跟在关键字后面
# def bad(max_turns=5, user):             # 语法错：默认值形参不能排在必填前面

Agent 配置里大量默认值：agent_loop(max_turns=5)、rag_search(..., top_k=3)。 模型省略某个字段时，函数仍能跑。

4. *args / **kwargs，以及调用时的 **

这是本课最要记住的一条，因为 0003 已经在用它。

写法出现位置含义
*args定义函数多出来的位置参数收成一个 tuple
**kwargs定义函数多出来的关键字参数收成一个 dict
*seq调用函数把序列拆成位置参数
**mapping调用函数把 dict 拆成关键字参数
def rag_search(query, top_k=3):
    return [{"query": query, "top_k": top_k}]

arguments = {"query": "what is harness", "top_k": 2}

# 两行完全等价（官方教程叫 “dictionaries can deliver keyword arguments”）
rag_search(query="what is harness", top_k=2)
rag_search(**arguments)

模型吐出的 tool call 几乎总是 {"name": "...", "arguments": {...}}。 harness 不知道每个工具要哪些字段，于是：查注册表得到函数，再 fn(**arguments)。 字段对不上会 TypeError——所以 run_tool 要接住它，变成可观察的 error，而不是把进程打死。

def foo(*args, **kwargs) 能吞任意参数，调试方便，作公共 API 时会把错误推迟到函数内部。 工具函数优先写出明确形参（query、top_k），让错误发生在调用那一刻。

5. 可变默认值：只创建一次

官方教程有一条警告：默认值在定义函数时求值一次，不是每次调用都新建。 默认值如果是 list / dict，多次调用会共用同一个对象——Java 里「每次 new ArrayList」的直觉在这里是错的。 

def bad_collect(item, bucket=[]):
    bucket.append(item)
    return bucket

bad_collect("a")  # ['a']
bad_collect("b")  # ['a', 'b']  ← 不是 ['b']

def good_collect(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket

history=[] 和上面的 bucket=[] 是同一条规则，不是 Agent 另有一套坑。 [] 在 def 被执行时创建一次；之后凡是没传这个参数的调用，拿到的都是同一个 list 对象。 Java 在方法里写 new ArrayList<>() 才是每次新建；Python 把可变对象写在默认参数上，更像给函数配了一个静态共享字段。 

def agent_loop(user_msg, history=[]):
    history.append(user_msg)
    return history

agent_loop("用户A：检索 harness")
# ["用户A：检索 harness"]
agent_loop("用户B：你好")
# ["用户A：检索 harness", "用户B：你好"]  ← B 的会话里漏进了 A

进程还活着，这个默认 list 就还在。重新跑一次 python examples.py 会重新定义函数，默认值会再创建一次；「漏」的范围是同一次运行里的多次调用，不是写进磁盘、也不是跨机器。

默认改成 None、进函数再 []，两次没传 history 的调用就各拿一份新 list，A / B 不会串：

def agent_loop(user_msg, history=None):
    if history is None:
        history = []          # 这次调用才新建
    history.append(user_msg)
    return history

agent_loop("用户A：检索 harness")  # ["用户A：检索 harness"]
agent_loop("用户B：你好")          # ["用户B：你好"]

None 只修「没传参数时误共用」。同一场对话要记上下文，必须自己拿着一份 list 反复传入——这时累加是刻意的： 

session = []
agent_loop("第一句", history=session)
agent_loop("第二句", history=session)  # session == ["第一句", "第二句"]

工具缓存同理：def get_tool(name, cache={}) 会让所有调用共用一本 dict。 做成进程内缓存可以是故意的；当成「这一次请求的临时表」就会在请求之间漏数据。可变对象默认用 None，进函数再创建；要共享就显式传入或放到模块级变量上，别靠默认参数暗共用。

6. 模块：一个 .py 就是一个命名空间

官方 Modules 章：模块是包含定义的文件，文件名去掉 .py 就是模块名。 tools.py 里的 run_tool、TOOLBOX 都活在名叫 tools 的命名空间里。 tools 是模块（整个 .py 文件加载后的那个对象），不是函数，也不是函数列表。 它比 run_tool 大：抽屉里现在有 read_file、rag_search、shell、TOOLBOX、run_tool。 run_tool 只是其中一个函数。 import 不是「复制一份代码进来」，而是：加载那个文件（每个进程只加载一次），再决定在你当前这个文件里出现哪些名字。

下面四行加载的都是同一份 tools.py。差别只在「写完这行之后，你能用哪个名字去摸 run_tool」。

写法当前文件多了谁怎么调用当前文件没有谁
import tools 模块名 tools tools.run_tool(...) 短名 run_tool（直接写会 NameError）
from tools import run_tool 函数名 run_tool run_tool(...) 模块名 tools（不能写 tools.TOOLBOX）
from tools import run_tool as exec_tool 别名 exec_tool exec_tool(...) tools 和 run_tool
import tools as t 别名 t t.run_tool(...) 原模块名 tools

本课主脚本用的是第二种：loop.py 里 from tools import run_tool，所以函数体里直接 run_tool(name, args)。 run.py 同理：from loop import agent_loop，然后 agent_loop()。 若改成 import tools，loop 里每一处都要写成 tools.run_tool——功能一样，只是名字带前缀，两个模块都有 foo 时不容易撞车。

和 Java 对照：

  • import tools ≈ import com.foo.Tools;，用时写 Tools.run()
  • from tools import run_tool ≈ static import，用时直接 run_tool()
  • as 是给名字换短称；Java 没有同等语法，Python 里用来避免撞名或缩短长模块名
  • 后写的 from b import foo 会覆盖先写的 from a import foo。两个都要留，用 as 起不同名，或改回 a.foo / b.foo。
  • from tools import * 官方不推荐：你不知道污染了哪些名字。本课练习禁止用。
  • 解释器对每个模块只加载一次；改了 tools.py 要重新运行脚本（或重启 REPL），不是再 import 一次就会刷新。

跑对照（四个函数各自一块局部名字，互不污染）： import_styles.py 

python 0004-functions-modules\import_styles.py

盯住每段的两个 True/False：写法1 只有 tools；写法2 只有 run_tool。四种调用打印的 error 内容相同，因为摸的是同一份 run_tool。

模块里的 __name__：被 import 时是模块名（如 "tools"）；作为脚本直接运行时是 "__main__"。 所以入口写成： 

if __name__ == "__main__":
    agent_loop()

直接 python run.py 会开转；别人 import run 只拿到函数，不会自动跑 loop。0003 已经这样写了，现在你知道它在防什么。

目录 + __init__.py 才叫包（package）。本课先平铺几个模块；包的结构以后拆更大项目再用。

  3. 0003 用 lambda 当工具，本课改成具名函数。 lambda 是一次性匿名函数（Day16 才会系统讲）。注册表需要稳定、可测试、带文档的工具时，具名 def 更合适。 TOOLBOX["rag_search"] 存的是函数对象，不是调用结果——注意没有后面的 ()。

    Python 把「被运行脚本所在目录」放进模块搜索路径，所以这四个文件互相 import 时，你从 playground\python 跑 python 0004-functions-modules\run.py 也找得到它们。
  5. 读 run_tool 时对照例 3：TOOLBOX[name](**arguments) 就是把模型的 dict 展开。删掉 ** 变成 TOOLBOX[name](arguments)，工具函数会收到一个 dict 当 query，立刻 TypeError。

常见坑 + 边界

  • 调用写成了定义：TOOLBOX["rag_search"] 是函数；TOOLBOX["rag_search"]() 才是调用。注册表里必须存前者。
  • 漏掉 **：fn(arguments) 把整个 dict 塞进第一个形参；fn(**arguments) 才按键名对上。
  • 可变默认值：def f(xs=[]) 与 history=[] 是同一对象被反复 append。独立对话用 None 再新建；同一场对话显式传入同一份 list。详见第 5 节。
  • 同名覆盖：from a import foo 再 from b import foo，只剩 b.foo。用 as 或 a.foo。
  • 改了模块但 REPL 没刷新：模块只加载一次。练习场请直接重新 python run.py，别在半开的交互里 import 完再改文件。
  • 和 Java 易混：Python 参数没有「按类型重载」；同名后定义覆盖前定义。默认参数也不是每次调用 new。
  • 命名关键字（形参列表里的光杆 *）本课跳过；以后在库函数签名里见到「必须写 k=...」再认。
