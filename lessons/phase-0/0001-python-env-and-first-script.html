Python 环境确认与第一支脚本

使命需要你能读改 Agent/RAG 的 Python 代码。今天只做一件事：证明本机 Python 可用，并跑通第一支文件脚本（不是聊天框里的片段）。

你已经有的

本机已检测到 Python 3.12.9。安装故事可以跳过；把精力留给「项目目录 + 虚拟环境 + 跑文件」。

今天要完成的步骤

  1. 打开 PowerShell，确认： 
    python --version
pip --version
  2. 在统一练习场建虚拟环境（所有阶段 0 脚本都放这里）： 
    cd d:\agent-learning
mkdir playground\python\0001-hello -Force
cd playground\python
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python --version

    约定：练习代码 → playground/python/课号-主题/；共用 playground/python/.venv。不要写进 python-100Days/。
    若激活被策略拦住：Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

  3. 写文件 playground/python/0001-hello/hello_agent.py： 
    import sys

print("ready for agent stack")
print("python:", sys.version.split()[0])
print("mission: internship harness + RAG")
  4. 运行（venv 已激活时）： 
    python 0001-hello\hello_agent.py
    看到三行输出即过关。

为什么这样学（对照 Java）

  • venv ≈ 每个项目独立依赖，类似「模块不污染全局 classpath」。
  • Agent 教程几乎都用 Python；你的 Java 能力后面用 API/MCP 接业务，不在今天重写 runtime。
