本课概念Java 直觉关键差异

系统讲解

1. 名字两个词，循环三个环节

ReAct = Reasoning + Acting（推理 + 行动）。 书立刻补了一刀：实际还有「看」。

模型先思考当前应该做什么，然后调用工具行动，再观察工具返回的结果并继续思考下一步。 这个“想 → 做 → 看 → 想 → 做 → 看”的循环不断重复，直到任务完成。

原文：书 §1.1.5 L172 。North README 搜 ReAct 会空——它画的是同一件事，叫「最小循环」。

环节谁干0017 / 0018 落点
想Model 看上下文，决定调不调工具、调哪个Agency / 大脑
做Harness 执行 tool_call（真读文件、真跑命令）最小 Harness：工具接口
看Environment 给出观察；Harness 追加进轨迹观察 → 上下文；环境仍在公式外

工具调用的 API 展开是四步：先在上下文里声明有哪些工具，再让模型选，再执行并追加，再决策。 后三步就是想 / 做 / 看；第一步是静态前缀里的工具定义。

四步：书 L72 （它说这是后文 ReAct 的基础）。

2. 每次看见的上下文 = 静态前缀 + 轨迹

轨迹：用户消息、模型回复（思考 + 工具调用）、工具结果，随交互变长。 静态前缀：系统提示词 + 工具定义；每次调模型都拼在轨迹前面，所以轨迹列表里往往看不到它们。

「Agent 的上下文 = 静态前缀 + 轨迹」：书 L174 ；前缀不写进轨迹示例： L226。

关键事实（接 0017）：工具结果如果没被追加进轨迹，下一轮「想」就等于没发生过这次「看」。 磁盘上有文件，不等于模型看见了。 

context = stable_prefix + trajectory
decision = Model(context)
trajectory.append(decision)
# 若有 tool_call：执行 → observation 再 append

书最小骨架 L181–195 。伪代码不能当 SDK 跑。

3. 代码只执行模型的要求

North 把最小循环画成：用户消息进列表 → 调 LLM → 看停因为什么。

User --> messages[] --> LLM --> response
                              stop_reason == "tool_use"?
                         yes /              \ no
                  执行工具、追加结果           返回文本
                  再 loop 回 messages[]

原文图： README-zh.md L140–159。 定性句在 L156–157： 「模型决定何时调用工具、何时停止。代码只是执行模型的要求。」

stop_reason：模型结束本轮生成时附带的原因。 本课只认对比：值为 tool_use → 还要做；不是 → 说完了，把文本当答案返回。 书用「没有 tool call 就返回」，不绑某一家 API 字段名。

North 骨架用 if response.stop_reason != "tool_use": return： L219–220。 书： L189–190。

叠回 0018：循环属于把驾驶者一遍遍送上赛道； 权限、压缩、hooks 是挂在循环上的机制，不改这根骨架。 README 也写了：「循环属于 agent。机制属于 harness。」阶段 2 从 s01 起往上叠，本课不动它。

L234 ；s01 格言「一个工具 + 一个循环」在 L165 （只记句子，不打开 code.py）。

4. 下一步谁决定：三种情况

形状都可以像 while。要看下一发 tool_call 从哪来。

案下一步从哪来判定
① Model 读完整轨迹（含上次观察）再输出 ReAct / 自主 Agent。本课要认的这一种
② fake_model(turn)：第 0 轮、第 1 轮作者写死 0003 预习。有 while、有工具，但决策者不看轨迹
③ 代码写死：先 read，再数 TODO，再拼答案 工作流（0017）。LLM 即使出现也只在节点内填字

① 和 ② 跑完都可能得到「2 个 TODO」。 差别不在答案，在假如观察变了，下一步会不会变。 ② 的第 1 轮照样念剧本；① 会按新的轨迹想。

自主 Agent「本质上就是在一个循环中使用工具的 LLM」：书 §1.2.4.2 L415 （一句话指针，不展开框架表）。

5. 怎么停：三种情况

自主不等于转到地老天荒。停止条件要设计。

案条件出现在哪
① 正常完成 没有 tool call / stop_reason != tool_use 书 L189；North L219。本课主出口
② 安全带 达到最大轮数（0003 的 max_turns） 书 L413 「最大迭代次数」。North 这段骨架是 while True，没写触顶——缺了要自己补
③ 失败停 不可恢复错误 同一句 L413；细节 0020 / 阶段 2

常见退出条件并列：书 L415 （最终输出工具 / 无工具调用 / 错误或最大轮数）。

常见坑 + 边界

  • 0003 已经会了循环：会的是 Python while。ReAct 问的是谁看轨迹做决定。
  • 在循环里写 if 规划步骤：那是工作流 / 水管工。最小循环里代码执行调用，不选路。
  • North 里搜不到 ReAct：书用这个词；README 用「最小循环」。同一根骨架。
  • 轨迹丢了工具结果：下一轮想等于没看。不是模型「忘了」，是你没喂。
  • README 骨架 while True 就够了：正常出口靠 stop_reason；最大轮数书要求有，骨架没写，生产要补。
  • 本课去跑 s01 / 去读 L01：过密。真循环阶段 2；失败归因已在 0020。
