阶段 2 · 能动手

阶段 0 已补齐读 North 所需的 Python，阶段 1 已钉住 Agent 的公式、Harness 和失败归因。本阶段开始真正运行 North 根目录的 s01–s17/code.py，每课只在同一根 Agent loop 上增加一个机制。

材料怎么配

  1. 先读对应 North 章节的 README，建立问题和运行目标。
  2. 再跑该章根目录的 code.py；本阶段不把旧的 docs/、agents/ 章节混进来。
  3. 卡在「为什么要这层约束」时，再看书 Ch4 / Ch5 或 Harness 讲义对应段落。

阶段 1 的概念课仍可回看： 阶段 1 分册。 课上代码以 North 当章 code.py 为准，非必要不另写 playground。
