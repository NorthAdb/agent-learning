# Learner

本仓库专用。老师每轮 `/alvar-teach` 先读这份，再读 `NOTES.md` / `MISSION.md`。

## How I learn
- Pace: 先读当课 HTML，再用 Alvar 摸底 / 一步一测锁住。不要另开一套课。
- Struggle: 练习代码由老师创建；我以读代码 + 运行为主。卡住可以改着玩。
- Explanations I want: 简体中文；概念 → 规则 → 小例；Java 对照；新词当场定义并给可点开的出处。
- Explanations I do not want: 一次倒完整课；把「去看 DayXX / 去看书第 N 章」当成讲解；临场发挥不画计划图。
